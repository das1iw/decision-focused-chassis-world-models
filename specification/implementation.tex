\begin{abstract}
This supplement specifies the planner objective, actuator mapping, physical coefficients, friction hypotheses and training settings underlying the manuscript. It is assembled from saved implementation sources and training receipts. It adds no training, simulation, frozen-test rescore or empirical tire-force result. Full-precision fitted coefficients and learning arguments accompany the source. Native CarSim replication requires separately licensed software and vehicle assets.
\end{abstract}

\section{Coordinates, state and integration}
The wheel order is front left, front right, rear left, rear right. Body $x$ points forward and $y$ left; positive yaw and steering turn left. Units are SI unless stated. The mechanical state is $s=(v_x,v_y,r,\omega_{1:4},T_{1:4})$. Physical memory is $h=(\tau_{1:4},\kappa_{L,1:4},a_{x,f},a_{y,f},F_{x,\mathrm{prev},1:4},F_{y,\mathrm{prev},1:4})$, with $\tau=\tan\alpha_L$. World pose, steering/torque limiter states and the preceding normalized action are retained. The residual MLP has no learned memory; the residual GRU adds 32 memory units per wheel. State and memory initialization use simulation; production-sensor reconstruction is unvalidated.

Each 0.02 s prediction step contains five 0.004 s physical substeps. The native CarSim plant instead uses 40 solver substeps per command interval. Physical derivatives use forward Euler; slip and filtered-acceleration memory use exponential updates. Pose is advanced using midpoint body velocities and yaw rate over the command interval.

\section{Complete drift-planner value and command generation}
The fixed planner maximizes the following undiscounted value over $H=75$ steps (1.5 s):
\begin{align}
G_j={}&\sum_{k=0}^{H-1}I_k\left[\frac{s_{k+1}^{\mathrm{tr}}-s_k^{\mathrm{tr}}}{20\Delta t}
\exp\!\left(-\frac{e_{y,k+1}^2}{2^2}-\frac{(\beta_{k+1}-\beta^{\mathrm{ref}}_{k+1})^2}{(15\pi/180)^2}\right)\right.\nonumber\\
&\left.\hspace{8mm}-0.01\|a_k-a_{k-1}\|_2^2-20[|\beta_{k+1}|-40\pi/180]_+^2-10D_k\right]\nonumber\\
&-I_H\left(2[v_H-v_{\lim,H}]_+^2+0.5\{e_{y,H}^2+[5\sin(e_{\psi,H}+\beta_H)]^2\}\right).
\label{eq:value}
\end{align}
$[x]_+=\max(x,0)$; $a_{-1}$ is the preceding normalized command; $s^{\mathrm{tr}}$ is course station; and $v=\sqrt{v_x^2+v_y^2}$. Sideslip is $\operatorname{atan2}(v_y,\max(v_x,0.5))$. The sideslip-tracking factor applies everywhere in the reported drift configuration, including the zero target outside drift zones.

$I_k$ indicates survival before step $k$, and $D_k$ indicates the first invalid step: $|e_y|>6.5$ m (5 m course half-width plus 1.5 m margin), $|\beta|>70$ degrees, $|e_\psi|>110$ degrees, or nonfinite mechanical state. That step contributes its reward and the $-10$ penalty; subsequent steps contribute zero. Terminal penalties apply only to survivors. A nonfinite final value is replaced by $-10^6$. These are prediction-value rules; the harness implements native episode completion, low-speed failure and time-limit handling separately.

Course geometry has 0.5 m spacing. Each predicted position is projected onto the nearest point in the local window; tangent projection gives station and signed lateral error. The window starts ten stations behind the current index and spans $40H\Delta t+50+20$ m. With course curvature $\kappa_c$, the target is
\[
\beta^{\mathrm{ref}}=-\operatorname{sign}(\kappa_c)(25\pi/180)
\operatorname{clip}((|\kappa_c|-1/80)/(1/80),0,1).
\]
The speed envelope starts from $v_c=0.75\sqrt{\mu g/\max(|\kappa_c|,10^{-4})}$. Corners up to 50 m ahead are checked at 5 m spacing. Allowable upstream speed is limited by deceleration $\min(0.8\mu g,P/(mv))$, with $P=240$ kW and $g=9.80665$ m/s$^2$, and minimized across preview corners. The exact friction/power transition is specified by \src{envelope_vlim} in the source snapshot.

Candidates are $A_j=\operatorname{clip}(U+\epsilon_j,-1,1)$, with independent Gaussian perturbations: standard deviation 0.25 for each steering channel and 0.35 for each wheel-torque channel. Candidate zero is the unperturbed sequence. Initially $U=0$. Weights are $w_j\propto\exp(G_j-\max_qG_q)$ (temperature one). The complete weighted sequence $\bar U=\sum_jw_jA_j$ is formed; only its first action executes. Its tail is shifted and final element repeated for the next warm start. The usual candidate count is 512; the computation comparison includes physics with 2048. The external native block uses planner seed 1. NumPy/CuPy implementations need not generate identical draws from the same seed.

\section{Friction bank and simulation prior}
The native harness uses 17 hypotheses $\mu_j=\mu_0f_j$, with $f_j=0.60,0.65,\ldots,1.40$, anchored at the initial $\mu_0$ without recentering. Every five command steps (0.1 s), applied commands are replayed through physics alone from the observed start state and tracked memory. This observer/bank is unchanged across physics, residual and adapted-ExpTanh planning arms.

The endpoint observation is $(v_x,v_y,r,\omega_{1:4})$. Fixed standard deviations are
\[\sigma=(0.0094,0.0363,0.0145,1.2352,0.8470,2.3800,1.7767),\]
with m/s for the first two channels and rad/s otherwise. These constants were calibrated originally on 0.2 s windows and reused in the 0.1 s configuration. Starting from flat weights, the update is
\[
\ell_j\leftarrow0.9\ell_j-\tfrac12\sum_c((z_c-\hat z_{j,c})/\sigma_c)^2.
\]
After subtracting the largest log weight, probabilities are normalized, floored at $10^{-3}$ and normalized again. The planner receives the discrete 0.1 quantile of the fixed hypotheses. Neither this quantile nor the reused noise scales establish calibrated uncertainty or a certified conservative friction bound.

\textbf{Initialization boundary.} Nominal native tests supply $\mu_0$ equal to the initial simulated coefficient; the overestimate condition uses $1.2\mu_{\mathrm{true}}$. No separate native probe is run. A grip loss is unannounced. Thus subsequent motion-based updates do not establish inference from an unknown initial road. State, wheel/motor measurements and observer initialization also use simulation information.

\section{Learning configurations and partitions}
Recorded sequences cover courses 9027--9042. Forecast training holds out four whole courses, 9039--9042 (192 training, 64 validation episodes). Decision training holds out three, 9040--9042 (4160 training, 960 held-out decisions). These splits differ. Each of 5120 stored decisions retains 64 candidates, the twin's best 32 plus 32 random others. Each decision-training batch samples 32 decisions without replacement and 16 candidates from each half. All 64 stored candidates enter held-out evaluation. Separate full-bank evaluations address the difference from deployment. These are used development data.

\subsection{Residual networks and forecast training}
The wheel-shared MLP is 16--64--64--2 with SiLU hidden activations (5378 parameters); its final weights are scaled by 0.01 and biases set to zero at initialization. Features are
\begin{align*}
f_i={}&(\kappa_L,\arctan\tau,F_z/3000,\mu,v_l/20,v_t/10,\omega R/20,\\
&\delta,T/500,v_x/20,v_y/10,r,e_i),
\end{align*}
where $e_i$ is a four-component wheel identity, $\delta$ includes compliance and $T$ is realized torque. Forces receive $0.2\mu F_z\tanh(n_q)$ per axis; aligning moment stays from physics. A recurrent alternative uses a 16-input 32-unit GRU cell and 48--64--2 SiLU head per physical substep, sharing parameters across four separate wheel memories.

Forecast training uses horizons 5/15/25 with 600/600/800 updates, batch 128, Adam at $2\,10^{-3}$ and global gradient-norm clipping at one. Physics-containing training is float64. Recurrent residuals use ten teacher-forced warm-up steps; the memoryless residual uses none. The wheel-focused loss averages squared errors of $(v_x,v_y,r,\omega_{1:4})$ normalized by $(1,1,0.5,5,5,5,5)$.

The pose/sideslip variant averages $\sum_{q\in\{v_x,v_y,r,p,\psi,\beta\}}(\Delta q/s_q)^2+0.25\operatorname{mean}_i(\Delta\omega_i/s_\omega)^2$, integrating reference and predicted pose by the same midpoint rule. Scales are physics-only endpoint RMSE on up to 2000 training windows of length 25 and stride three. The selected MLP's scales are:

The generic learned baseline uses 11 normalized mechanical states, eight applied inputs and friction, a 128-unit GRU and two width-256 SiLU hidden layers to predict 11 state increments (164363 parameters). State scales are $(20,10,1,60,60,60,60,500,500,500,500)$; torque inputs are divided by 500. Its increment is $0.1$ times the state scales times the head output. \subsection{Decision training, seeds and normalization}
The manuscript's decision loss uses cross-entropy of twin/model weights plus 0.1 times centered-value mean squared error divided by the twin's sample variance plus $10^{-6}$; the variance denominator is $M-1$. Gradients span all 75 steps and five substeps per step with fixed physics. Finite, nonzero per-decision gradients are normalized to unit length and averaged; zero is assigned if none qualify. Norms accumulate in float64, with a $10^{-30}$ reciprocal floor. Assigning a zero direction does not clear existing Adam moments.

Training uses float32 rollouts, 600 updates and Adam at $10^{-3}$ with defaults $(\beta_1,\beta_2,\epsilon)=(0.9,0.999,10^{-8})$, no weight decay. The selected model starts from the pose/sideslip MLP and uses decision seed 2899 in trainer version 5. Other displayed normalized runs start from the wheel-focused MLP (2899) or near-zero-output initialization (2900). Independently forecast-trained seeds 290/291 precede decision seeds 2990/2991, using CUDA-graph trainer version 6. Final checkpoints enter the fresh-course comparisons without replica selection. The combined-loss variant adds 0.3 times forecast loss with 64 windows of length 25; its saved arguments state any extra regret term.

The raw batch-mean comparison uses 16 decisions, global clipping at one and a shorter 200-update observation, so it does not isolate normalization at matched budget. Version 5 computes per-decision linear-layer gradients with hooks; version 6 captures rollout/backward work in a CUDA graph. Both sources and original training arguments are retained. No new optimization ablation is claimed.

\subsection{Adapted neural-ExpTanh baseline}
The baseline implements the neural-ExpTanh formulation of Djeumou et al., ICRA 2023, adapting it to four driven/steered wheels. A coefficient network per axle maps $(r,V/20,\beta,\mu F_z/3000)$ through two tanh hidden layers to five coefficients; another maps $(\alpha,\sigma)$ to force direction. The selected width is 16, trained from scratch for 150 epochs, batch 4096, Adam learning rate $10^{-3}$, per-epoch decay 0.99, friction penalty 0.01, seed 307. Courses 9027--9039 supply 383406 training samples and 9040--9042 supply 90540 validation samples.

Wheel-spin inversion uses central differences of simulated motion for longitudinal forces. Lateral fitting uses body longitudinal/lateral and yaw equation errors, avoiding an invented left/right lateral allocation. The loss sums four wheel longitudinal residual squares, three body-equation residual squares (yaw divided by a 1.3 m lever), and the 0.01-weighted peak-force friction penalty; forces are normalized in kN.

Six development variants cover widths 3/16, with and without physics-force warm starts, and warm-started widths 16/32 with separate friction and load inputs. The chosen width-16 published-feature variant minimizes nominal development RMS lateral error among variants with no more crashes than physics. The same rule selected the development residual. The frozen external test uses this comparator and two unselected residual replicas on courses 8701--8716 with 512 candidates. The 30\% result concerns this adapted implementation, vehicle, data and fixed MPPI planner; it is not a reproduction or general ranking of the original nonlinear MPC system, or a benchmark against the newer conditional-diffusion method.

\section{Analytical force-boundary diagnostic}
For $\rho_i=\|F_i\|_2/(\mu F_{z,i})$, component-wise bounds imply
\[
\|\Delta F_i\|_2/(\mu F_{z,i})\leq0.2\sqrt2\simeq0.282843,
\qquad \rho_i^{\mathrm{corrected}}\leq\rho_i^{\mathrm{physics}}+0.2\sqrt2.
\]
Even if the base resultant is at most one, the upper bound is 1.282843, not friction-circle feasibility. The base is a load-dependent tire-table model; $\mu F_z$ is a diagnostic scale, not proof that each base force obeys a unit circle. No projection is applied. This bound describes what is permitted, not an observed exceedance rate, force-identification result or new scored experiment. Empirical exceedance counts and a projected-force intervention need separate diagnostics and evaluation.

\section{Artifacts, reproduction levels and remaining boundaries}
Accompanying JSON files specify full-precision fitted parameters and saved training arguments. The source snapshot and SHA-256 inventories identify implementations, four selected/replicate/comparator checkpoints and original scorer/checker receipts. The sequence and decision datasets occupy 76933168 and 574493236 bytes. A public release must include these shareable datasets and installation/reproduction instructions; a local inventory alone does not establish public availability or a tested installation. Native replication additionally requires the licensed simulator and vehicle assets. Numerical reproducibility is conditional on these dependencies and the execution environment.

The independently checked external-test receipt agrees with the scorer on primary statistics and verdicts. This supplement reads saved receipts; no frozen test is rescored. Complete courses remain the statistical units. Some grip-loss results are mixed, drift-zone improvement is not generally significant, physical force accuracy is unvalidated, and CarSim waits for planning decisions. Kernel cost matching and average planning latency do not establish a strict 20 ms sensing-to-actuation deadline, calibrated uncertainty or real-vehicle performance.
